Arduino Ultrasonic Radar System 🎯

An IoT-based educational project that detects nearby objects using an ultrasonic sensor mounted on a servo motor and visualizes their approximate direction and distance through a Python graphical interface.

🚀 Project Overview

The system uses an Arduino UNO, an HC-SR04 ultrasonic sensor, and a servo motor to scan the surrounding area. Distance and angle readings are transmitted to a computer through serial communication and displayed using Python and Tkinter.

✨ Features

- Ultrasonic distance measurement
- Servo-based scanning from approximately 15° to 165°
- Radar-style graphical visualization
- Serial communication between Arduino and Python
- Visual representation of detected objects
- Display of scanning angle and distance

🛠️ Technologies Used

- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- Servo Motor
- Arduino C/C++
- Python
- Tkinter
- PySerial

📂 Project Structure

- "hardware/" — Arduino source code, circuit diagram, and hardware photograph
- "software/" — Python radar GUI and dependencies
- "images/" — Project screenshots
- "tests/" — Testing report

⚙️ Working Principle

1. The servo motor rotates the ultrasonic sensor.
2. The sensor measures the distance to nearby objects.
3. The Arduino sends angle and distance readings to the computer.
4. Python receives the readings through serial communication.
5. Tkinter displays detected objects on a radar-style interface.
